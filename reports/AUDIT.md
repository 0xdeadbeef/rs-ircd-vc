## Regenerating

```bash
cargo run --release --bin audit -- report
cargo run --release --bin audit -- markers --check
cargo run --release --bin audit -- speed --json
cargo run --release --bin audit -- security --soak 200000
```

`report` exits non-zero when a marker is malformed or duplicated, or when an executable check fails, so it can be used as a gate.

## Scope and limits

* The marker register records what was reviewed and where; it is not a proof of correctness, and absence of a marker is not absence of risk.
* Static counts are textual, not semantic: an `unsafe` mentioned in a comment counts as an `unsafe` block.
* Speed numbers come from one shared virtual machine and are only comparable within a single run of this binary.
* The security checks cover the parser, the tag relay, wildcard cost and the credential comparison. They do not cover TLS pinning, link authentication, rate limits or filesystem exposure.
